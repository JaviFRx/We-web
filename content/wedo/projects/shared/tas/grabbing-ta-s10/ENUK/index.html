Programming Help

Creating a Timer

This program will count down every second. To change the total amount of time that is allowed for this challenge, change the start number on the first block and adjust the number of times that the loop should count down before stopping.

Differentiation Opportunities and Collaboration

Here are three different ways in which you can use the robotic arm:

  • Give each team one minute to move objects from point A to point B. The distance between A and B can vary (but use a distance of approximately one metre). LEGO® bricks are great objects to move, but any small and light objects will work.

  • Practice your precision by seeing how many blocks you can move from point A to point B in one minute.

  • Have the teams pair up. Have the first team use the robotic hand to grab a pencil, write a word on a piece of paper and hand the pencil off to the second team’s robotic arm. The second team should then write the same word and put down the pencil.
