Caractéristiques du modèle

Les élèves doivent construire un robot pouvant se déplacer et tourner, puis programmer ce robot pour qu’il se déplace sur une surface.

Les élèves peuvent utiliser les petits modules, pour que le robot les ramasse, ou construire leurs propres modules.

Voici certains éléments dont les élèves doivent tenir compte lors de la construction de ce modèle :

  • Les pneus avant sont plus grands que le pneu arrière.

  • Le fil du moteur ne doit pas interférer avec le mécanisme.

  • Les pneus sont montés correctement sur leur moyeu.

Option de construction par équipe

Si vous avez suffisamment de dispositifs, vous pouvez réduire le temps de construction de ce modèle en demandant à chaque élève de construire une partie du robot de son équipe :

  • L'élève A peut construire des étapes 1 à 23.

  • L'élève B peut construire des étapes 24 à 41.
