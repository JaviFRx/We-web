Programmierhilfe

Um einen Klang aufzunehmen, drücken Sie im Bedienfeld auf das Mikrofonsymbol.

Nehmen Sie einen Klang auf. Verändern Sie dann die Aufnahme mit den Funktionen im Fenster, um einen eigenen Klang zu erstellen.

Wenn Sie damit fertig sind, können Sie diesen Klang als Klangnummer 0 verwenden. Wenn Sie einen neuen Klang aufnehmen, wird der zuletzt aufgenommene Klang überschrieben.
