Caractéristiques du modèle

Les élèves vont construire un levier de commande utilisant un détecteur d’inclinaison. Le détecteur d’inclinaison détecte la position dans laquelle le levier de commande est incliné. Ces positions sont appelées des « modes ». Les élèves peuvent programmer une sortie différente pour chacun de ces modes, comme l'émission d’un son ou l’affichage d’une couleur.

Construire un levier de commande à l’aide du détecteur d’inclinaison

Le détecteur d’inclinaison peut détecter des changements parmi les six modes suivants :

  • Incliner de l’autre côté

  • Incliner d’un côté

  • Incliner vers le haut

  • Incliner vers le bas

  • Aucune inclinaison

  • Secouer

Dans la première partie du projet, les élèves doivent utiliser trois modes :

  • Incliner vers le haut, pour le son court du code Morse

  • Incliner vers le bas, pour le son long du code Morse

  • Aucune inclinaison, pour l’absence de son

Dans la deuxième partie du projet, les élèves peuvent utiliser les six modes.
