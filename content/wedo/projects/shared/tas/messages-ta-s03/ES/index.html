Características del modelo

Los estudiantes construirán un mando que utilice un sensor de inclinación. El sensor de inclinación detectará la posición en la que se inclina el mando. Estas posiciones se denominan “modos”. Pueden programar una salida diferente para cada uno de estos modos, como reproducir un sonido o mostrar un color.

Construcción de un mando que utilice un sensor de inclinación

El sensor de inclinación puede detectar cambios en seis modos diferentes:

  • Inclinación en un sentidoa la izquierda

  • Inclinación a la derecha

  • Inclinación hacia arriba

  • Inclinación hacia abajo

  • Sin inclinación

  • Agitar

En la primera parte del proyecto, los estudiantes usarán tres modos:

  • Inclinación hacia arriba, para el sonido corto del código Morse

  • Inclinación hacia abajo, para el sonido largo del código Morse

  • Sin inclinación, para que no haya sonido

En la segunda parte del proyecto, los estudiantes pueden usar los seis modos.
