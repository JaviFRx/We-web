Characteristics of the Model

The pupils will build a joystick that uses a Tilt Sensor. The Tilt Sensor will detect the position in which the joystick is tilted. These positions are called ‘modes’. They can program a different output for each of these modes, such as playing a sound or displaying a colour.

Build a Joystick Using the Tilt Sensor

The Tilt Sensor can detect changes within six different modes:

  • Tilt Left

  • Tilt Right

  • Tilt Up

  • Tilt Down

  • No Tilt

  • Shake

In the first part of the project, the pupils will use three modes:

  • Tilt Up, for the short sound of Morse code

  • Tilt Down, for the long sound of Morse code

  • No Tilt, for no sound

In the second part of the project, the pupils can use all six of the modes.
