Compétences en matière de logique informatique

L’évaluation n’englobe pas nécessairement toutes ces compétences : l’accent peut être mis sur les compétences qui sont le plus pertinentes pour vos élèves et vous.

Permettre aux élèves de trouver des similitudes (généralisation)

Une similitude est quelque chose qui peut être appliqué de la même manière dans différentes situations. Voici quelques similitudes que vos élèves doivent prendre en compte pour ce projet :

  • Comment ouvriront-ils et fermeront-ils la main ?

  • Comment le détecteur de mouvement peut-il être utilisé dans ce modèle ?

  • Quel(s) mouvement(s) sera(ont) répété(s) plusieurs fois ?

Permettre aux élèves de programmer une séquence d’actions (pensée algorithmique)

Les élèves devront identifier une séquence d’actions qui feront fonctionner leurs bras robotiques. Demandez-leur de décrire les étapes qu’ils souhaitent coder (ex : ouvrir la pince, attendre 2 secondes, fermer la pince, etc.).

Invitez les élèves à retranscrire ce processus en utilisant l’outil de documentation.

Permettre aux élèves d’améliorer leur solution (évaluation)

L’un des défis de ce projet est que les élèves comprennent comment leur modèle fonctionne réellement. Le fait de comprendre les limites voire d’améliorer la conception de leurs modèles amènera les élèves à ajuster les paramètres dans leurs programmes afin d’améliorer l’efficacité et la précision.

Vous pouvez organiser une session de partage entre les équipes ou en groupes pour que vos élèves puissent partager des stratégies ou des astuces pouvant les aider à améliorer leurs solutions.

Aide pour la programmation

Maintenir la pression sur un objet

Pour maintenir la pression sur un objet, il est recommandé de programmer le moteur pour qu’il reste allumé lors de la capture de l’objet. La main humaine fonctionne exactement de cette manière.
