Présentation du projet

Dans cette section du projet, les élèves découvriront le détecteur de mouvement qu’ils utiliseront pour détecter la présence d’un échantillon de plante particulier.

Type de projet

Ce projet découverte vous permettra, à vous ainsi qu’à vos élèves, de vous familiariser avec d’autres éléments des projets WeDo 2.0, notamment :

  • explorer les manières d’utiliser le détecteur de mouvement

  • enregistrer une vidéo avec l’outil de capture

Durée

Env. 20 minutes
