Milo programmieren, damit der eine Nachricht an Max und Mia sendet

Beim Drücken auf den grünen Pfeil:

  1. Programm starten

  2. Warten, bis sich der Neigungssensor abwärts neigt

  3. LED mit Farbe 9 (rot) einschalten

  4. Text „ “ anzeigen

  5. Warten, bis sich der Neigungssensor aufwärts neigt

  6. LED ausschalten mit Farbe 0 (keine Farbe)

  7. Text „Milo“ anzeigen

  8. Schritte 2 bis 7 unendlich wiederholen

Achten Sie darauf, dass die Schülerinnen und Schüler die richtige Eingabe für den Neigungssensor verwenden. Sie können den Modus verändern, indem Sie auf die Eingabe drücken. Wenn Sie einen anderen Modus verwenden, wird Milo anders reagieren.
