Program Milo to Send a Message to Max and Mia

When the green arrow is tapped:

  1. Start program

  2. Wait for Tilt Sensor to Tilt Down

  3. Turn on LED to colour 9 (red)

  4. Show text “ “ on the display

  5. Wait for Tilt Sensor to Tilt Up

  6. Turn off LED to colour 0 (no colour)

  7. Show text ‘Milo’ on the display

  8. Repeat steps 2 to 7 forever

Make sure that your students are using the correct input for the Tilt Sensor. You can change the mode by tapping on the input. Using a different mode will make Milo react differently.
