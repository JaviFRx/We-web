Programar a Milo para que envíe un mensaje a Max y Mia

Al tocar la flecha verde:

  1. Iniciar el programa

  2. Esperar a que el sensor de inclinación se incline hacia abajo

  3. Encender el LED en el color 9 (rojo)

  4. Mostrar el texto " " en la pantalla

  5. Esperar a que el sensor de inclinación se incline hacia arriba

  6. Apagar el LED en el color 0 (sin color)

  7. Mostrar el texto "Milo" en la pantalla

  8. Repetir los pasos 2 a 7 para siempre

Asegúrese de que sus estudiantes utilizan la entrada correcta para el sensor de inclinación. Puede cambiar el modo tocando la entrada. Si utiliza un modelo diferente, Milo reaccionará de forma diferente.
