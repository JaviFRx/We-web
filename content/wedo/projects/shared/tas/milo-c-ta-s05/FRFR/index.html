Programmez Milo pour envoyer un message à Max et Mia

Lorsque vous appuyez sur la flèche verte :

  1. Lancer le programme

  2. Attendre que le détecteur d’inclinaison s’incline vers le bas

  3. Allumer le voyant sur la couleur 9 (rouge)

  4. Afficher le texte «   » à l’écran

  5. Attendre que le détecteur d’inclinaison s’incline vers le haut

  6. Éteindre le voyant sur la couleur 0 (aucune couleur)

  7. Afficher le texte « Milo » à l’écran

  8. Recommencer les étapes 2 à 7 indéfiniment

Assurez-vous que vos élèves utilisent la bonne entrée pour le détecteur d’inclinaison. Vous pouvez changer de mode en appuyant sur l’entrée. L’utilisation d’un mode différent fera réagir Milo différemment.
