Aide pour la programmation

Programmez Milo pour détecter l’échantillon de plante

Lorsque vous appuyez sur la flèche verte :

  1. Lancer le programme

  2. Démarrer le moteur à la puissance 4

  3. Démarrer le moteur dans le sens 2

  4. Attendre que le détecteur de mouvement détecte l’objet

  5. Arrêter le moteur

  6. Jouer le son 1

Assurez-vous que vos élèves utilisent la bonne entrée pour le détecteur de mouvement. Vous pouvez changer de mode en appuyant sur l’entrée. L’utilisation d’un mode différent fera réagir Milo différemment.
