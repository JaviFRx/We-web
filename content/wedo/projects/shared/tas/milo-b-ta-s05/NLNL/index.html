Programmeerhulp

Milo programmeren om de plant te detecteren

Wanneer op de groene pijl wordt getikt:

  1. Start het programma

  2. Start de motor op vermogen 4

  3. Start de motor in de andere richting

  4. Wacht tot de bewegingssensor het object heeft gedetecteerd

  5. Stop de motor

  6. Speel geluid 1 af

Zorg ervoor dat je leerlingen de juiste input voor de bewegingssensor gebruiken. Je kunt de modus wijzigen door op de input te tikken. Als je een andere modus gebruikt, reageert Milo op een andere manier.
