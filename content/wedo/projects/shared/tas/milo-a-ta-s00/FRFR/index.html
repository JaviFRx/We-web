Présentation du projet

Ce projet a pour objectif de faire découvrir les manières dont les scientifiques et les ingénieurs peuvent utiliser des astromobiles pour explorer des endroits inaccessibles aux humains.

Type de projet

Ce projet découverte vous permettra, à vous ainsi qu’à vos élèves, de vous familiariser avec certains éléments importants des projets WeDo 2.0, notamment :

  • engager une discussion

  • construire un modèle LEGO

  • connecter le Smarthub à un dispositif

  • programmer un modèle LEGO

  • prendre une photo avec l’outil de capture

  • écrire dans l’outil de documentation

Durée

Env. 45 minutes

Étapes suivantes

Consultez les parties B, C et D du projet « Milo, l’astromobile scientifique ».
