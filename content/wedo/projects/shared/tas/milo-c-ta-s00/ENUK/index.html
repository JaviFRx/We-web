Overview of the Project

In this section of the project, the pupils will be introduced to the Tilt Sensor, which they will use in order to help Milo to send a message to Max and Mia.

Type of Project

This Getting Started Project will enable you and your pupils to get in touch with more elements of the WeDo 2.0 projects, including:

  • Exploring ways to use the Tilt Sensor

  • Using the Capture tool to take a screen capture of a program

Duration

Approx. 20 minutes
