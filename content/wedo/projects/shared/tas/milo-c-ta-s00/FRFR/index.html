Présentation du projet

Dans cette section du projet, les élèves découvriront le détecteur d’inclinaison qu’ils utiliseront pour aider Milo à envoyer un message à Max et Mia.

Type de projet

Ce projet découverte vous permettra, à vous ainsi qu’à vos élèves, de vous familiariser avec d’autres éléments des projets WeDo 2.0, notamment :

  • explorer les manières d’utiliser le détecteur d’inclinaison

  • utiliser l’outil de capture pour faire une capture d’écran d’un programme

Durée

Env. 20 minutes
