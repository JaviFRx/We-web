Información general sobre el proyecto

En esta sección del proyecto se presentará a los estudiantes el sensor de inclinación, el cual usarán para ayudar a Milo a enviar un mensaje a Max y a Mia.

Tipo de proyecto

Este proyecto de Primeros pasos le permitirá a usted y a sus estudiantes entrar en contacto con algunos elementos más de los proyectos de WeDo 2.0, que incluyen:

  • Explorar diferentes maneras de usar el sensor de inclinación

  • Usar la herramienta de captura para hacer una captura de pantalla de un programa

Duración

20 minutos aprox.
