Computational Thinking Skills

Assessment does not have to encompass all of these skills, an emphasis can be placed on the skills that are most relevant to you and your students.

Enable Students to Find Patterns (Generalization)

A pattern is something that can be applied in the same way in different situations. Here are some patterns your students should consider for this project:

  • How can they send the short signal of Morse code?

  • How can they send the long signal of Morse code?

Enable Students to Program a Sequence of Actions (Algorithmic Thinking)

The students will need to code a sequence of actions that will send signals representing the word “Max” or “Mia.” In Morse code, the word “Max” would be: M (long, long); A (short, long); X (short, short, short, short).

The students could use several different strategies:

  1. Code by word: program the entire word when the joystick is tilted up.

  2. Code by letter: program the letter “M” when the joystick is tilted up, “A” when it’s tilted down, and “X” when it’s tilted left.

  3. Code by sound (like a Morse code device): program the short sound when the joystick is tilted up, and the long sound when it’s tilted down. With this option, students would need to move the joystick in order to send the message. Here is one of the possible solutions for this option:

The students will test their programs and adjust the parameters they think will make their device work better.
