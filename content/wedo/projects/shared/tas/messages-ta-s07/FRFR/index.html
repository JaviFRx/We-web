Permettre aux élèves de programmer une séquence d’actions (pensée algorithmique)

Les élèves doivent coder une séquence d’actions pour envoyer des signaux représentant le mot « Max » ou « Mia ». En code Morse, le mot « Max » est : M (long, long); A (court, long) ; X (court, court, court, court).

Les élèves peuvent utiliser plusieurs stratégies différentes.

  1. Coder par mot : programmer le mot complet lorsque le levier de commande est incliné vers le haut.

  2. Coder par lettre : programmer la lettre « M » lorsque le levier de commande est incliné vers le haut, « A » lorsqu’il est incliné vers le bas et « X » lorsqu’il est incliné vers la gauche.

  3. Coder par son (comme un dispositif à code Morse) : programmer le son court lorsque le levier de commande est incliné vers le haut et le son long lorsque le levier de commande est incliné vers le bas.
