Geförderte Kompetenzen – informatisches Denken

Bei der Lernstandserhebung müssen nicht alle Kompetenzen erfasst werden. Sie können selbst wählen, welche davon für Sie und Ihre Klasse relevant sind und entsprechende Schwerpunkte legen.

Muster erkennen können (Generalisierung)

Ein Muster ist etwas, das in verschiedenen Situationen auf gleiche Weise angewendet werden kann. Im Folgenden finden Sie einige wiederkehrende Muster, die Ihre Schülerinnen und Schüler berücksichtigen sollten:

  • Wie kann man ein kurzes Morsesignal versenden?

  • Wie kann man ein langes Morsesignal versenden?

Eine Abfolge von Befehlen programmieren können (Algorithmisches Denken)

Die Schülerinnen und Schüler sollen eine Abfolge von Befehlen kodieren, um Signale zu versenden, die das Wort „Max“ oder „Mia“ bilden. Das Wort „Max“ lautet im Morsecode: M (lang, lang); A (kurz, lang); X (kurz, kurz, kurz, kurz).

Die Schülerinnen und Schüler können verschiedene Strategien anwenden:

  1. Code für Wort: das gesamte Wort programmieren, wenn der Joystick nach oben geneigt wird.

  2. Code für Buchstabe: den Buchstaben „M“ programmieren, wenn der Joystick nach oben geneigt wird, „A“, wenn er nach unten geneigt wird, und „X“, wenn er nach links geneigt wird.

  3. Code für Klang (wie ein Morsegerät): den kurzen Ton programmieren, wenn der Joystick nach oben geneigt wird, und den langen, wenn er nach unten geneigt wird. Bei dieser Methode müssen die Schülerinnen und Schüler den Joystick bewegen, um die Nachricht zu versenden. Eine mögliche Lösung für diese Methode:

Lassen Sie sie diese Vorgehensweise im Dokumentationstool aufzeichnen.

Lösungen verbessern können (Evaluation)

Die Schülerinnen und Schüler testen ihre Programme und passen die Parameter an, wenn sie denken, dass das Gerät dadurch besser funktionieren wird.
