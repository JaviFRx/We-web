L’évaluation n’englobe pas nécessairement toutes ces compétences : l’accent peut être mis sur les compétences qui sont le plus pertinentes pour vos élèves et vous.

Permettre aux élèves de trouver des similitudes (généralisation)

Une similitude est quelque chose qui peut être appliqué de la même manière dans différentes situations.

Voici quelques similitudes que vos élèves doivent prendre en compte pour ce projet :

  • Comment le dispositif d’alarme signale-t-il la phase du volcan ?

  • Comment le détecteur de mouvement peut-il être utilisé dans ce modèle ?

  • Quel(s) mouvement(s) est(sont) répété(s) ?

Permettre aux élèves de programmer une séquence d’actions (pensée algorithmique)

Les élèves programment leurs alarmes pour donner l’alerte lorsque l’aiguille s’arrête sur la position rouge. Demandez-leur de décrire les étapes qu’ils souhaitent programmer (ex : lorsque l’alarme vibre, activez le moteur, attendez de voir où elle s’arrête, donnez le signal approprié en fonction de la position du dispositif).

Permettre aux élèves d’améliorer leur solution (évaluation)

L’un des défis de ce projet est de comprendre le lien entre l’alarme, le programme et les objets qui doivent être déplacés. Demandez à vos élèves d’évaluer s’ils pensent que leur solution répond à tous ces critères :

  • L’alarme est activée lorsqu’elle est secouée

  • Le moteur est activé pendant un nombre de secondes aléatoire

  • Le détecteur d’inclinaison est utilisé pour détecter la phase du volcan

  • À chaque fois que la phase rouge est atteinte, le drone se déplace dans le volcan

Vous pouvez organiser une session de partage entre les équipes ou en groupes pour que vos élèves puissent partager des stratégies ou des astuces pouvant les aider à améliorer leurs solutions.

Aide pour la programmation

Utiliser le détecteur d’inclinaison

La phase rouge du dispositif d’alarme est atteinte lorsque le détecteur d’inclinaison est incliné vers le bas.

Les élèves peuvent affecter différents types d’alarme lors de cette phase, comme un son, un voyant ou des images d’un volcan en éruption.
