Creación de un programa para activar la mano

Este programa permitirá a sus estudiantes controlar la apertura y el cierre de la mano. Deje un poco de tiempo para que los estudiantes exploren y jueguen mientras se familiarizan con los movimientos del brazo.

Ayuda para la programación

Uso del sensor de movimiento para manejar la mano

El sensor de movimiento detecta, de tres maneras distintas, los cambios de distancia respecto de un objeto dentro de un radio determinado:

  • Objeto que se acerca

  • Objeto que se aleja

  • Objeto que cambia de posición

Para cambiar el modo de detección, toque el bloque de entrada.

Existen diferentes formas de activar la mano mediante un sensor de movimiento. El sensor puede detectar la mesa, el objeto que hay que agarrar o el movimiento de otra mano que se agita frente al sensor.
