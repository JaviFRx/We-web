Créer un programme pour activer la main

Ce programme permettra aux élèves de contrôler l’ouverture et la fermeture de la main. Donnez du temps à vos élèves pour qu’ils explorent, jouent et se familiarisent avec les mouvements du bras.

Aide pour la programmation

Utiliser le détecteur de mouvement pour faire fonctionner la main

Le détecteur de mouvement détecte les changements de distance d’un objet de trois façons différentes, sous réserve que cet objet se trouve dans la portée d’action du détecteur.

  • Objet se rapprochant

  • Objet s’éloignant

  • Objet changeant de position

Pour changer le mode de détection, appuyez sur le bloc d’entrée.

Il y a de nombreuses façons d’activer la main en utilisant un détecteur de mouvement. Le détecteur peut détecter la table, l’objet à attraper ou le mouvement d’une autre main qui s’agite devant le détecteur.
