Using the Motion Sensor to Operate the Hand

The Motion Sensor detects changes in distance from an object within its range in three different ways:

  • Object moving closer

  • Object moving farther away

  • Object changing position

To change the detection mode, tap on the input block.

There are many ways in which to activate the hand using a Motion Sensor. The sensor can detect the table, the object to grab, or the movement of another hand waving in front of the sensor.
