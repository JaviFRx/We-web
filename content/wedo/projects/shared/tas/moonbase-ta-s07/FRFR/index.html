Compétences en matière de logique informatique

L’évaluation n’englobe pas nécessairement toutes ces compétences : l’accent peut être mis sur les compétences qui sont le plus pertinentes pour vos élèves et vous.

Permettre aux élèves de trouver des similitudes (généralisation)

Une similitude est quelque chose qui peut être appliqué de la même manière dans différentes situations. Voici quelques similitudes que vos élèves doivent prendre en compte pour ce projet :

  • Faire tourner le robot de 90 degrés vers la gauche pour qu’il se déplace vers la gauche

  • Faire tourner le robot de 270 degrés vers la gauche pour qu’il se déplace vers la droite

  • Contrôler le déplacement vers l’avant

Permettre aux élèves de programmer une séquence d’actions (pensée algorithmique).

Les élèves doivent coder une séquence d’actions pour que leur robot se déplace. Pour les aider à programmer, demandez à vos élèves de décrire le chemin qu’ils prévoient de suivre. Ils devraient répondre par une expression du type : « le robot ira ici, tournera à gauche, ira là, tournera de nouveau à droite, puis s’arrêtera ».

Invitez les élèves à retranscrire ce processus en utilisant l’outil de documentation.

Permettre aux élèves d’améliorer leur solution (évaluation).

Les élèves doivent tester leurs programmes et ajuster leurs paramètres pour en améliorer l’efficacité et la précision. Pour les aider à programmer, demandez à vos élèves d’identifier le bloc de leur programme qu’ils doivent ajuster.

Faire déplacer le robot vers la droite

Pour faire tourner le robot de 90 degrés vers la droite, les élèves doivent le programmer pour qu’il tourne de 270 degrés vers la gauche. Il est possible que les élèves doivent ajuster la durée, selon leur moteur et le niveau de la batterie.
