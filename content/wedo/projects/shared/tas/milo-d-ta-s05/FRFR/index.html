Programmer le dispositif de transport pour l’équipe de Milo

Laissez les élèves créer leurs propres séquences de programmation, afin qu’ils puissent déplacer l’échantillon d’un point A à un point B. L’emplacement du point A ou du point B n’est pas important.

En raison de nombreux facteurs (différences entre les moteurs WeDo 2.0, différences de construction de Milo…), les équipes devront collaborer afin de coordonner les mouvements de leur dispositif de transport.

Aide pour la programmation

Les élèves peuvent utiliser les séquences de programmation suivantes, qui leur permettront de contrôler un côté du dispositif de transport.

Lorsque vous appuyez sur la première flèche verte :

  1. Lancer le programme

  2. Démarrer le moteur dans le sens 2

  3. Démarrer le moteur à la puissance 8

  4. Démarrer le moteur pendant 2 secondes

Lorsque vous appuyez sur la deuxième flèche verte :

  1. Lancer le programme

  2. Arrêter le moteur

Demandez aux équipes de modifier ces séquences de programmation pour améliorer le comportement de leur dispositif de transport.
