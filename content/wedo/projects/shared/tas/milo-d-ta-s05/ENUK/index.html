Program the Team Milo Transportation Device

Let the pupils create their own program strings so that they can move the specimen from point A to point B. It doesn’t matter where point A or point B is.

Because of many factors, such as WeDo 2.0 motors being different or small differences in the Milo builds, the teams will have to collaborate in order to coordinate the movements of their transportation device.

Programming Help

The pupils could use the following program strings, which will allow them to control one side of the transportation device.

When the first green arrow is tapped:

  1. Start program

  2. Start motor that way

  3. Start motor at power 8

  4. Start motor for 2 seconds

When the second green arrow is tapped:

  1. Start program

  2. Stop motor

Have the teams change these programming strings in order to improve the behaviour of their transportation device.
