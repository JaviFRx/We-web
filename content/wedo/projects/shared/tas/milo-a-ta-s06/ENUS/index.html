Programming Help

Program Milo to Move Forward

When the green arrow is tapped:

  1. Start program

  2. Start the motor at power 8

  3. Start the motor that way

  4. Start the motor for 2 seconds

  5. Stop the motor

Controlling the Motor

The motor can be:

  • Started in both directions

  • Stopped

  • Started at different speeds

  • Started for a specific amount of time (specified in seconds)

Stopping all actions at any time

A program string can always be stopped by pressing on the Stop icon.

Modifying the Program String

Give students time to change the parameters of this program string. Let them discover new features, such as adding sound.

Using the Program Library

If you want, you can use this opportunity to guide your students to the Program Library so they can gain inspiration about other program strings they can explore.
