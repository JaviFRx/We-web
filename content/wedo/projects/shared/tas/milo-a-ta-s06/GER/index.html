Programmierhilfe

Milo programmieren und vorwärts laufen lassen

Beim Drücken auf den grünen Pfeil:

  1. Programm starten

  2. Motor mit Leistungsstufe 8 starten

  3. Motor in jene Richtung starten

  4. Motor für 2 Sekunden starten

  5. Motor stoppen

Den Motor steuern

Der Motor kann:

  • in beide Richtungen gestartet werden

  • gestoppt werden

  • mit unterschiedlichen Drehzahlen gestartet werden

  • für eine vorgegebene Zeit (in Sekunden) lang gestartet werden

Alle Aktionen zu einem beliebigen Zeitpunkt anhalten

Ein Programm kann jederzeit gestoppt werden, indem Sie auf das Stopp-Symbol drücken.

Programme ändern

Geben Sie den Schülerinnen und Schülern Zeit, die Parameter dieses Programms zu verändern. Lassen Sie sie neue Funktionen entdecken (z. B. Klänge hinzufügen).

Die Programmbibliothek verwenden

Wenn Sie möchten, können Sie die Schülerinnen und Schüler bei dieser Gelegenheit auf die Programmbibliothek hinweisen. Hier können sie Anregungen zu anderen Programmierbausteinen finden, die sie verwenden können.
