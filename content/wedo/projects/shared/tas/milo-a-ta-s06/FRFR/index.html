Aide pour la programmation

Programmez Milo pour qu’il se déplace vers l’avant.

Lorsque vous appuyez sur la flèche verte :

  1. Lancer le programme

  2. Démarrer le moteur à la puissance 8

  3. Démarrer le moteur dans le sens 2

  4. Démarrer le moteur pendant 2 secondes

  5. Arrêter le moteur

Contrôler le moteur

Le moteur peut être :

  • démarré dans les deux sens

  • arrêté

  • arrêté à différentes vitesses

  • démarré pendant une durée spécifique (précisée en secondes)

Arrêter toutes les actions à tout moment

Une séquence de programmation peut toujours être arrêtée en appuyant sur l’icône Arrêter.

Modifier la séquence de programmation

Donnez aux élèves le temps de modifier les paramètres de cette séquence de programmation. Laissez-les découvrir de nouvelles fonctionnalités telles qu’ajouter du son.

Utiliser la bibliothèque des programmes

Si vous le souhaitez, vous pouvez orienter vos élèves vers la bibliothèque des programmes afin qu’ils puissent trouver de l’inspiration pour d’autres séquences de programmation à explorer.
