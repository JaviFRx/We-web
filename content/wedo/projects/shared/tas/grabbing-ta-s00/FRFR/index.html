Type de projet

Ce projet est axé sur le développement des compétences en matière de logique informatique. Bien que le projet mobilise l’ensemble des cinq compétences ci-dessous, l’accent peut être mis sur celles qui sont les plus pertinentes pour vos élèves et vous.

Dans ce projet, l’accent peut être mis sur les points suivants :

  • Décomposition : simplifier le problème en identifiant les mouvements qu’une main robotique peut reproduire

  • Généralisation : trouver des similitudes dans la façon dont la main robotique peut s’ouvrir et se fermer

  • Pensée algorithmique : créer un programme pour attraper et relâcher des objets

  • Évaluation : déboguer des programmes en détectant les erreurs

  • Abstraction : expliquer la solution avec le bon niveau de détails

Planifier une séquence pédagogique

Préparation : 30 minutes

  • Lisez le projet et la documentation pertinente figurant dans l’Aide-enseignant.

  • Définissez la façon dont vous souhaitez présenter ce projet. Vous pouvez utiliser la vidéo fournie avec le projet ou utiliser votre propre contenu.

  • Déterminez le résultat final de ce projet. Par exemple, définissez les paramètres des présentations de vos élèves et les éléments spécifiques qu’ils doivent inclure dans leurs documents.

  • Vérifiez que les délais prévus permettent aux élèves de répondre aux attentes.

Phase d’exploration : 10 - 45 minutes

  • Démarrez le projet en montrant la vidéo ou en présentant votre propre contenu sur le sujet.

  • Animez une discussion en groupe.

  • Donnez à vos élèves la possibilité de documenter leur travail en utilisant l’outil de documentation.

Phase de création : 20 minutes

  • Faites construire à vos élèves le premier modèle en suivant les instructions de construction.

  • Faites-leur programmer le modèle avec le programme exemple.

  • Donnez-leur le temps de comprendre le modèle qu’ils utiliseront.

Phase de test : 25 minutes

  • Lisez la première tâche avec vos élèves.

  • Donnez-leur du temps pour qu’ils puissent planifier, essayer et tester leur solution.

  • Lisez la deuxième tâche avec vos élèves.

  • Donnez-leur du temps pour qu’ils puissent planifier, essayer et tester leur solution.

Phase de création supplémentaire (facultative) : 45 - 60 minutes

  • Si vous le souhaitez, vous pouvez utiliser cette phase supplémentaire du projet pour approfondir le sujet ou pour des élèves plus âgés.

Phase de partage : 45 minutes ou plus

  • Assurez-vous que les élèves documentent leur travail.

  • Utilisez différentes méthodes pour que les élèves partagent ce qu’ils ont appris et leurs réflexions sur ces expériences.

  • Demandez-leur de créer leur rapport final et de présenter leur projet.
