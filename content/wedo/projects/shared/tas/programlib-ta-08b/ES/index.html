Ayuda para la programación

Se pueden conectar dos sensores al hub inteligente al mismo tiempo. Pero, en tal caso, el hub inteligente no puede controlar el motor.

Para controlar más sensores y motores a la vez, puede conectar hasta tres hubs inteligentes al mismo dispositivo.

Para cambiar la letra de activación, mantenga pulsado el bloque para acceder al teclado.

En una tableta sin teclado externo, todas las cadenas con la misma letra se iniciarán al mismo tiempo cuando se toque una de ellas.

En un ordenador o en una tableta con teclado externo, todas las cadenas con la misma letra se iniciarán al mismo tiempo cuando se pulse la letra correspondiente en el teclado.
