Geförderte Kompetenzen – informatisches Denken

Nutzen Sie diese Aufgabe, um einzuschätzen, ob die Schülerinnen und Schüler das Wissen aus der vorherigen Aufgabe anwenden können.

Differenzierungsmöglichkeiten

Im Folgenden finden Sie zwei alternative Umsetzungsmöglichkeiten für diese Projektphase:

  • Lassen Sie die Schülerinnen und Schüler Antennen konstruieren. Diese sollen so programmiert werden, dass sie sich in die Richtung drehen, in die sie eine Nachricht senden oder aus der sie eine Nachricht empfangen wollen.

  • Lassen Sie die Schülerinnen und Schüler selbst erkunden, wie Satelliten funktionieren, indem sie das Modell eines Satelliten bauen und erklären, wie Nachrichten damit übertragen werden.
