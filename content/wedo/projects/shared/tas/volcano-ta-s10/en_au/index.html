Programming Help

Using the Existing Program to Create an Additional Stage

The needle of the alarm can already point to three different colours: green, yellow and red. A fourth stage, the orange stage, can be created within the existing program. When the needle points to red, the program can select a random colour that can be understood in the following way:

  • If orange is selected, this is the orange stage

  • If red is selected, this is the red stage

  • If other colours are selected, this is an error in the system

Opportunities for Differentiation and Collaboration

Here are two alternative ways to conduct this phase of the project:

  • Have the students keep statistics on the different stages of the volcano, and use this information to calculate different things such as percentage, average or probability.

  • Have the teams create new rules about how the drone, the rover and the animal should behave in response to the different volcano stages. Pair up the teams so that they can exchange the rules and explore the volcanoes.
