Ayuda para la programación

Usar el programa existente para crear un estado adicional

La aguja de la alarma ya puede apuntar a tres colores diferentes: verde, amarillo y rojo. Puede crearse una cuarta fase, la fase naranja, en el programa existente. Cuando la aguja apunta al rojo, el programa puede seleccionar un color aleatorio que puede entenderse de la siguiente forma:

  • Si se selecciona el naranja, esta es la fase naranja

  • Si se selecciona el rojo, esta es la fase roja

  • si se seleccionan otros colores, se trata de un error del sistema

Oportunidades de diferenciación y colaboración

Aquí puede ver dos alternativas para dirigir esta fase del proyecto:

  • Haga que los estudiantes recopilen estadísticas sobre las diferentes fases del volcán y utilicen esta información para calcular otros elementos como porcentajes, promedios o probabilidades.

  • Haga que los equipos creen nuevas reglas sobre cómo deben funcionar el dron, el vehículo y el animal según las fases del volcán. Empareje los equipos para que puedan intercambiar sus reglas y explorar los volcanes.
