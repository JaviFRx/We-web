Programmierhilfe

Mit dem bestehenden Programm eine zusätzliche Stufe erstellen

Der Zeiger des Warngeräts kann bisher auf drei verschiedene Farben zeigen: Grün, Gelb und Rot. Es kann aber noch eine vierte Stufe – Orange – zum bestehenden Programm hinzugefügt werden. Wenn das Gerät auf Rot zeigt, kann das Programm eine Farbe zufällig auswählen. In diesem Fall gibt es folgende Interpretationsmöglichkeiten:

  • Wird orange ausgewählt, liegt die Stufe „orange“ vor.

  • Wird rot ausgewählt, liegt die Stufe „rot“ vor.

  • Wird eine andere Farbe ausgewählt, liegt ein Fehler im System vor.

Differenzierungsmöglichkeiten und Zusammenarbeit

Im Folgenden finden Sie zwei alternative Umsetzungsmöglichkeiten für diese Projektphase:

  • Lassen Sie die Schülerinnen und Schüler Statistiken zu den verschiedenen vulkanischen Aktivitätsstufen anfertigen. Mit diesen Daten können sie dann verschiedene Berechnungen anstellen (z. B. Prozentanteil, Durchschnitt oder Wahrscheinlichkeit).

  • Lassen Sie die Gruppen neue Regeln dazu festlegen, wie sich die Drohne, die Sonde und das Tier bei den verschiedenen vulkanischen Aktivitätsstufen verhalten sollen. Lassen Sie jeweils zwei Gruppen zusammenarbeiten, die dann untereinander die neuen Regeln austauschen und gemeinsam die Vulkane erkunden.
